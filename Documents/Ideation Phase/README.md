# 📄 Project Documentation & Reports

This folder contains all formal reports and project artifacts generated during the ideation, implementation, and deployment phases of the **Laptop Request Catalog Item** ServiceNow project.

These files provide the complete narrative, rationale, and evidence necessary to understand the solution from both a user-centric and technical perspective.

---

## Folder Contents

| File Name | Description | Focus Area |
| :--- | :--- | :--- |
| **Brainstroming-Idea Generation-Prioritization.pdf** | Documents the structured brainstorming session, idea grouping, and the final solution prioritization matrix (Importance vs. Feasibility). | **Ideation & Strategy** |
| **Define Problem Statement.pdf** | Outlines the core organizational problem, the structured problem statements (User Experience Statements), and the identified challenges in the manual process. | **Problem Definition** |
| **Empathy Map Canvas.pdf** | Provides the user-centric analysis, capturing the employee's pains, gains, thoughts, and feelings to guide an empathetic design approach. | **User-Centric Design** |

---

## Key Project Highlights

* **Problem Solved:** Replacing a manual, slow, and non-dynamic laptop request process.
* **Core Solution:** A dynamic ServiceNow Catalog Item utilizing **Catalog UI Policies** and a **Client UI Action** (Reset Button).
* **Governance:** All configurations were tracked and migrated using a dedicated **Update Set** to ensure safe and repeatable deployment.

For the technical steps and code snippets, please refer back to the main repository's root **README.md**.
