# 🎥 Demo Video: Laptop Request Catalog Item

This folder contains the demonstration video for the **Laptop Request Catalog Item** project, showcasing its functionality within the ServiceNow platform.

---

## 📘 About the Demo

The video walks through the key features of the catalog item, including:
- Dynamic field behavior using UI Policies
- Form reset functionality via Client UI Action
- Submission flow and user experience
- Governance setup using Update Sets

This demo was created to support project evaluation and provide a visual overview of the solution in action.
